## 🔧 Alternative: Automated API Deploy

If you want fully automated deployment:

1. **Get Render API Key:**
   ```
   https://dashboard.render.com/u/settings?add-api-key
   ```

2. **Add to Cursor Secrets:**
   - Go to: cursor.com/settings
   - Cloud Agents > Secrets
   - Add: `RENDER_API_KEY` = (your key)

3. **I'll deploy automatically:**
   ```bash
   python3 deploy_to_render.py
   ```
